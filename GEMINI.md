# clearCNV Project Workflow Guide (MCP Server Integration)

This guide outlines the main steps for processing spatial transcriptomics data using `clearCNV` via the MCP server, from data loading and denoising to CNV inference and evaluation. This assumes you have already set up your environment and installed the necessary dependencies as detailed in the `README.md`.

## Core Workflow Steps

The `clearCNV` project workflow is structured around a series of MCP server tool functions, each performing a specific task:

1.  **`load_data_tool`**: Prepares your raw `.h5ad` spatial transcriptomics data.
2.  **`train_model_tool`**: Trains the Masked Autoencoder (mAE) on the prepared data.
3.  **`denoise_data_tool`**: Applies the trained mAE to denoise your raw data.
4.  **`run_infercnv_pipeline_tool`**: Executes the `infercnvpy` pipeline on both raw and denoised data.
5.  **`evaluate_cnv_tool`**: Quantifies the improvement in CNV signal detection.

## Step-by-Step Usage

### 1. Load and Prepare Data

Use `load_data_tool` to convert your raw `.h5ad` file into a `.pt` file suitable for model training. This tool handles loading cell x gene counts, spatial coordinates, and gene genomic positions.

```python
print(default_api.load_data_tool(
    input_h5ad_path='clearCNV/datasets/Xenium5K_human_prostate_subset.h5ad',
    output_pt_path='clearCNV/datasets/processed/processed_data.pt',
    fraction=0.1,
    n_neighbors=6,
    genes_per_bin=20
))
```

*   `input_h5ad_path`: Path to your input AnnData file.
*   `output_pt_path`: Desired path for the processed output. This `.pt` file will be used for training.
*   `fraction`: Fraction of cells to subsample (default: 0.1).
*   `n_neighbors`: Number of neighbors for the spatial graph (default: 6).
*   `genes_per_bin`: Number of genes per bin (default: 20).

### 2. Train the Masked Autoencoder (mAE)

Train the mAE model using `train_model_tool`. This step learns a low-dimensional representation and a denoising function for your data.

```python
print(default_api.train_model_tool(
    data_path='clearCNV/datasets/processed/processed_data.pt',
    output_dir='clearCNV/clearcnv_outputs/models',
    num_epochs=100,
    batch_size=8,
    lr=1e-4,
    warmup_steps=1000,
    spatial_weight=0.0,
    genomic_weight=0.0,
    mask_rate=0.15,
    print_every_n_batches=1000
))
```

*   `data_path`: Path to the `.pt` file generated by `load_data_tool`.
*   `output_dir`: Directory where trained model checkpoints will be saved.
*   Adjust optional parameters like `num_epochs`, `batch_size`, `lr`, `warmup_steps`, `spatial_weight`, `genomic_weight`, `mask_rate`, and `print_every_n_batches` as needed.

### 3. Denoise the Data

Once your mAE model is trained, use `denoise_data_tool` to apply it to your original raw `.h5ad` data, generating a denoised `.h5ad` file.

```python
print(default_api.denoise_data_tool(
    model_path='</path/to/your/best_model.pt>',
    raw_h5ad_path='</path/to/your/raw_data.h5ad>',
    denoised_h5ad_path='</path/to/your/denoised_data.h5ad>'
))
```

*   `model_path`: Path to the best trained model checkpoint (e.g., from `<output_dir>/model_epoch_XX.pt`).
*   `raw_h5ad_path`: Path to the original raw AnnData file.
*   `denoised_h5ad_path`: Desired path for the output denoised AnnData file.

### 4. Run inferCNV Pipeline

Execute the `infercnvpy` pipeline on both your raw and denoised `.h5ad` files using `run_infercnv_pipeline_tool`. This will generate CNV heatmaps for visual comparison and intermediate AnnData objects.

```python
print(default_api.run_infercnv_pipeline_tool(
    raw_h5ad_path='clearCNV/datasets/Xenium5K_human_prostate_subset.h5ad',
    denoised_h5ad_path='clearCNV/datasets/Xenium5K_human_prostate_subset_denoised.h5ad',
    raw_infercnv_h5ad_path='clearCNV/datasets/Xenium5K_human_prostate_subset_raw_infercnv.h5ad',
    denoised_infercnv_h5ad_path='clearCNV/datasets/Xenium5K_human_prostate_subset_denoised_infercnv.h5ad',
    raw_heatmap_path='clearCNV/clearcnv_outputs/raw_heatmap.png',
    denoised_heatmap_path='clearCNV/clearcnv_outputs/denoised_heatmap.png'
))
```

*Note: The `run_infercnv_pipeline_tool` now requires explicit paths for raw and denoised input/output AnnData files and heatmap images. Ensure these paths are correctly specified based on your project structure.*

### 5. Evaluate CNV Results

Finally, use `evaluate_cnv_tool` to quantitively assess the performance of the denoising by comparing the CNV metrics on raw vs. denoised `infercnv` results. This tool will return a scorecard summarizing the improvements.

```python
print(default_api.evaluate_cnv_tool(
    raw_adata_path='</path/to/raw_infercnv.h5ad>',
    denoised_adata_path='</path/to/denoised_infercnv.h5ad>',
    cell_type_key='<cell_type_column_name>',
    tumor_cell_type='<tumor_cell_type_name>',
    control_cell_type='<control_cell_type_name>'
))
```

*   `raw_adata_path`: AnnData file containing inferCNV results for raw data.
*   `denoised_adata_path`: AnnData file containing inferCNV results for denoised data.
*   `cell_type_key`: The column in your AnnData `.obs` dataframe that specifies cell types (e.g., `cell_type`, `annotations`).
*   `tumor_cell_type`: The specific cell type identified as tumor cells in your data.
*   `control_cell_type`: The specific cell type identified as control (diploid-like) cells in your data.

The tool will return a scorecard indicating Global CNV Contrast, Control Noise, Coherence, and False-Positive Guard metrics, along with their percentage changes, demonstrating the impact of the denoising.
